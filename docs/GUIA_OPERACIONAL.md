# Guia Operacional

## Antes da transmissão

1. Abrir o OBS
2. Conferir conexão da internet
3. Abrir Animated Lower Thirds
4. Executar o Pascom Live Manager
5. Preparar transmissão
6. Importar manualmente o JSON no Animated Lower Thirds
7. Conferir os textos
8. Iniciar a transmissão

O Pascom Live Manager gera o arquivo JSON de importação, mas não automatiza o clique de Import no Animated Lower Thirds. Essa etapa permanece manual para manter o fluxo previsível durante a transmissão.
